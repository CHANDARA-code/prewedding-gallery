# Project skills

Animation skills from [emilkowalski/skills](https://github.com/emilkowalski/skills) (MIT, see each folder's LICENSE),
copied verbatim at commit `5206a950b715e0cabe7043ea0b2304332b91494e` on 2026-11-09 after a full read-through:

- `find-animation-opportunities`: where the UI should (and shouldn't) animate
- `animate`: building an animation (gate, purpose, tool, properties, curve, duration, reduced motion)
- `review-animations`: reviewing motion code (user-invoked: `/review-animations`)
- `animation-performance`: keeping motion inside the frame budget

The app's motion tokens (`--ease-out`, `--ease-in-out`, `--ease-drawer`, durations) live at the top of
`apps/web/src/styles.css` and in the Ant Design theme (`apps/web/src/theme.ts`).
